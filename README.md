# e-Yantra

- Collaboration: Collaborated with a team of four from Miranda House to develop a ball-balancing platform with a maze, enabling the ball to navigate through the maze.
- Contributions: Developed a 3D maze and supporting platform in CoppeliaSim, and configured mass, inertia, and physics parameters to maintain simulation stability. Programmed a virtual image processing pipeline using Python (OpenCV) and Lua to capture and track ball coordinates from a simulated camera sensor.
- Experience: Gained practical experience in image processing, PID control systems, 3D design, algorithm development, and robotics simulation. The project strengthened problem-solving and teamwork skills
through the challenges of implementing the ball-balancing system.
